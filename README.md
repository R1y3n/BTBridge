# BTBridge

BTBridge bridge data forwarder for Linux only.

Its goal is to connect two or more Bluetooth endpoints and transparently forward data between them across various Bluetooth communication protocols.

## Features

* Bluetooth endpoint bridging
* Multi-device support
* Real-time data forwarding
* Linux only
